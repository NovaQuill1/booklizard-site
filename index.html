BookLizard 📚🦎

A lightweight, distraction-free desktop e-reader for macOS.

BookLizard is a simple, portable e-reader built with Python and Tkinter. Drop in your .txt or .rtf files and start reading instantly.

Download for macOS

Features

  • Clean, minimal reading interface
  • Multiple built-in reading themes
  • Keyboard navigation (arrow keys to turn pages)
  • Book selector and theme selector menu
  • User-editable books folder
  • Portable macOS .app

Adding Books

On first launch, BookLizard creates a folder at:

~/Documents/BookLizard/books

Drop your .txt or .rtf files into this folder, reopen BookLizard, and select a book from the menu.

Controls

  • ← / → — Turn pages
  • ESC — Open menu
  • TAB — Switch menu pages
  • 1–9 — Select book or theme

⚠️ macOS Security Notice ⚠️

Because BookLizard is not distributed through the App Store, macOS may block it on first launch.

To open it:

  1. Right-click BookLizard.app
  2. Select Open
  3. Click Open again

You only need to do this once.
